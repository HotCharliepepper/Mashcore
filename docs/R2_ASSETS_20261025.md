# R2 자산과 출처

첫 화면은 **AI 콘셉트**, 작업 흐름과 결과물은 **설명용 재구성**입니다. 실제 고객·사무실·현장 촬영 또는 성과 증거로 제시하지 않습니다. 최종 실사 자산과 공개 허락은 별도 확인 대상입니다. 화면에도 종류를 표시했습니다.

|---|---|---|---|

기계 판독 목록과 파일별 크기·SHA-256은 `content/assets-r2.json`, `source-media/manifest.json`에 있습니다. 임시 자산을 최종 승인으로 변경한 항목은 없습니다. 기존 R1 SVG도 삭제하지 않았습니다.

## 생성 맥락

Imagegen으로 만든 고유한 가상의 성인 인물·상점 앞 장면입니다. 제공된 seed.ai 비교 이미지는 PC/모바일 비율과 텍스트·인물 배치를 이해하는 용도로만 보았으며, 그 인물 사진·로고·문구를 생성 입력 자산으로 사용하지 않았습니다.

생성 프롬프트 요약(원문 전사 아님): 한국인 성인 남성이 작은 가게 입구에서 안내 카드를 살피는 조용한 낮 장면. 올리브색 재킷, 자연광, 나무 문과 크림색 벽. PC는 인물을 오른쪽에 두고 왼쪽에 HTML 문안을 놓을 여백. 실제 고객 사례로 오인될 로고·읽을 수 있는 상호·수치 없음. 모바일은 같은 가상 인물과 장소를 세로 3:4로 재구성하며 머리와 손이 함께 남게 요청.

생성 원본: `exec-1fd4dcc6-b1d8-49cc-8ca7-85d9b6c1375d.png` (1672×941), 모바일 편집 `exec-2a948175-f668-4dfe-bb2f-4d93ad0b2c3c.png` (1086×1448). 프로젝트에는 최적화한 결과가 보존됩니다. MP4는 이 이미지에 PC 2.5%, 모바일 2%의 느린 디지털 확대만 적용했습니다. 촬영 영상이나 인물의 실제 동작이 아닙니다.

영상은 poster가 준비된 후 요청하며 `playing` 이벤트에서만 자연스럽게 보입니다. 고정 대기 화면은 없습니다. 무음·인라인·1회 재생, 직접 일시정지/다시 보기, 화면 이탈·백그라운드 정지, 사용자 정지 존중, 모션 감소·데이터 절약·실패 시 정지 이미지 경로를 둡니다. 모션 시안이 부적절하면 `content/hero-media.json`의 영상 경로 둘을 null로 두어 포스터만 사용할 수 있습니다.

## 출처 참고와 적용 범위

- [제일기획](https://www.cheil.com/kr/) / [역량](https://www.cheil.com/kr/service/): 공식 페이지의 Work·Capabilities 연결과 역량별 관련 작업 진입 구조를 참고했습니다. 작품 이미지·레이아웃·성과 주장은 복제하지 않았습니다.
- [이상한마케팅](https://isanghan.co.kr/): 공식 페이지에서 메시지 → 이유와 근거 → 대상별 다음 행동 구조를 확인했습니다. 업체의 자기보고 수치·후기를 Mashcore의 근거로 사용하지 않았습니다.
- 첨부 `references/seed_ai_PC_mobile_user_reference.png`: 사용자 제공 비교 이미지. 구도 참고만 했으며 사이트에 게시하지 않았습니다.

참고 사이트는 2026-10-25 검색 도구로 공식 페이지의 내용과 링크 구조를 확인했습니다. 실제 브라우저의 픽셀 비교를 수행한 결과로 주장하지 않습니다.

## 소스 전달 방식

프로젝트의 `assets/media/`에 일반 WebP/MP4/PNG 파일을 보존합니다. 빌드가 이 파일을 복사한 뒤 `source-media/manifest.json`의 크기·SHA-256·경로와 대조합니다. 원본 목록·문서·테스트 페이지는 배포 산출물에 포함되지 않습니다. Git 연결의 binary blob API를 사용하며 브라우저에는 일반 미디어 파일로 전달됩니다.
