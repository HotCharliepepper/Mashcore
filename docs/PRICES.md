1회 프로젝트 가정은 제안이며 월정액 또는 기존 계약과 무관하다. VAT 포함 여부 미정. 총 결제액으로 단정하지 않고 실제 견적 전에 포함/별도 기준을 정한다. 수량·자료 규모·수정·제외 항목은 JSON에서만 수정한다. 광고비·촬영·출장·전체사이트/앱/CRM구현·상시운영·IP양도 자동 포함 없음. 카드 결제/PG/정기결제/할인/가짜 베스트셀러/정원/후기는 생성하지 않는다. 모든 상품 CTA는 해당 구성의 메일 초안을 작성하며 접수나 계약이 아니다.

정식 승인 시 필요한 작업: 상품과 세금 조건/영업 정보 확정 → 실제 사업·계약 문구 검수 → 사용자 승인 기록 → PROPOSED/검토안 문구 및 noindex·승인 게이트의 정식 출시에 맞는 변경을 별도 PR로 검수. 플래그만 바꿔 출시하지 않는다.
