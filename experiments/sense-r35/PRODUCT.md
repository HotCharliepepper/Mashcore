# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

기존 저장소의 정적 HTML/CSS/JavaScript. 사용자가 요청한 실행 가능한 독립 경로. 기존 GSAP 3.15.0 재사용.

## Product Purpose

사용자가 명시한 Origin → Second Look → Sense OS 세 장면으로 관찰, 가능한 설명, 다음 확인을 탐색한다. 서비스 CTA는 첫 장면에서 이해할 수 있어야 한다.

## Users

현장·브랜드·홈페이지 문의 흐름에 관심을 갖고 방문한 사람을 우선 상정한다. 이는 기존 서비스 본문에서 추론한 방문 상황이며 실제 사용자 조사 결과는 아니다.

## Capabilities and Constraints

세 가설을 사실로 확정하지 않는다. S31 시선 경로·예측가능성·통제감을 가상 인터랙션으로 설명한다. 고객 성과·실적·감정 측정 결과를 만들지 않는다. 운영 main과 PR #18을 읽기 전용 참고한다. 별도 Draft PR 및 Deploy Preview만 허용된다.

## Brand Commitments

MASHCORE 워드마크, R3.1의 숲색·종이색, 고운바탕, Origin 연출 장면, 기존 서비스·LAB·NOTES 내부 경로를 재사용한다. 이 실험은 기존 브랜드를 확장하며 전사 DESIGN.md를 교체하지 않는다.
