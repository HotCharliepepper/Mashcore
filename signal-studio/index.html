ONE SHOP / ONE QUESTION / ONE POST

대표가 확인할 것은
가게의 실제 이야기입니다.

현재 R2.1 로컬 검토 흐름은 세탁업의 고객 질문 하나를 중심으로 글과 네 장면, 사진 기반 영상을 준비합니다. 실제 매장 파일은 이 공개 페이지에 받지 않습니다.

  1. 01 / 설명

    가게를 들려주세요.

    누구를 돕고, 어떤 서비스를 제공하는지 대표가 설명합니다.

  2. 02 / 사실 확인

    맞는 말과 사진인가요?

    실제 사진의 출처와 안내할 사실을 확인합니다.

  3. 03 / 초안

    손님의 질문에 답합니다.

    게시 글과 네 장면의 설명을 만들고 문구를 수정합니다.

  4. 04 / 영상

    사진에 흐름을 더합니다.

    실사진 크롭·움직임과 한글 조판으로 사진 기반 MP4를 렌더합니다.

  5. 05 / 게시 안내

    대표가 직접 확인합니다.

    현재 버전을 승인·내보내고, 직접 게시할 때 필요한 안내를 받습니다.

IMPLEMENTATION STATUS / 검토 단계

작동하는 부분과,
아직 검증할 부분.

R2.1은 로컬 Gate 0 검토 구현입니다. 실제 사진 기반 샘플 MP4와 로컬 인증·저장·워커 코드가 있지만, 공개 유료 서비스나 원격 파일럿이 검증된 것은 아닙니다.

현재 구현 기준: 세탁업 질문 1개, Instagram 릴스 1채널, 고정 템플릿, 로컬 MP4 렌더. 요식업·정육업 등은 확장 방향입니다.

THE PURPOSE

첫 게시에 필요한 질문을,
복잡한 편집보다 먼저.

대표가 확인해야 할 사실과 문구를 분명히 하고, 콘텐츠 제작에 필요한 단계를 줄이는 것이 목표입니다. 공개 페이지의 버튼은 실제 계정 생성·체험 시작·결제·게시 완료를 수행하지 않습니다.
