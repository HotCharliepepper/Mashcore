# Mashcore — Small observations & Weplace portfolio v5

기록: 2026-10-19 KST. 상태: 작업 브랜치·프리뷰 검토본. 운영 반영 승인 대기.

## 목적과 고정 문안

고객의 작은 행동과 화면의 실제 구성에서 Mashcore의 역할을 이해하고, Weplace 프로젝트에서 적용의 범위를 확인한 뒤 자기 상황을 이야기할 수 있게 한다.

**역할:** 대표님의 사업을 함께 읽는 전략 파트너.

**히어로:** 작은 행동까지 살펴, 대표님의 일이 더 잘 전해지도록.

**설명:** 대표님들과의 현장 대화, 고객의 작은 행동, 화면 뒤의 구조를 함께 살펴봅니다. 그 속에서 얻은 관점을 대표님의 사업에 맞게 적용합니다.

| 장면 | 방문자의 질문 | 실제 행동 |
|---|---|---|
| 01 보다 | 무엇을 함께 살피는 곳인가? | 기존 문턱 구성 이미지·히어로 → 작은 차이 체험·대화 |
| 02 다르게 보다 | 작은 관찰을 어떻게 적용하는가? | 세 관점 선택 → 동일 안내의 A/B 배치 비교 |
| 03 현장에 놓다 | 어떤 프로젝트에 연결되는가? | Weplace 상세 읽기·공개 홈페이지 보기 |
| 04 함께 묻다 | 내 상황은 어떻게 이야기할 수 있는가? | 한 줄 작성·이메일 초안·문장 복사 |

## 관찰 체험

- 손의 움직임·읽는 순서·결정의 조건은 홈 체험의 세 관점이다.
- 구성 예시이며, A/B는 측정한 우열이 없는 비교 배치다.
- 같은 DOM 노드를 이동하여 정보 자체는 유지하고 시각·보조기기의 읽는 순서를 함께 바꾼다. 열린 native details 상태도 유지한다.
- 가설과 확인할 장면을 구분한다. 구매 증가·최적 위치·국적별 사용 비율을 만들지 않는다.
- 기존 공통 탭의 클릭·방향키·Home·End 동작을 사용한다.
- JavaScript가 없으면 세 문안을 모두 읽고 native details를 열 수 있으며 비작동 비교 조작부는 숨긴다.
- 체험은 클릭 기록·질문·센서 데이터를 수집하거나 저장·전송하지 않는다.

## Weplace

홈 카드와 /work/weplace/ 상세를 제공한다. 관계 표기는 **현장 실행 브랜드 · 전략·디지털 설계 협업**이다. 공개 홈페이지의 정보 구조·문구·자기 상황 탐색·상담 흐름을 중심으로 소개한다.

전체 소유·단독 개발·고객 DB 소유권·매출·검색 순위 성과를 주장하지 않는다. https://withweplace.kr/ 로 연결한다. 별도 PR #8 검토안을 운영 완료 자료로 옮기지 않는다. 상세의 도식은 ‘정보 흐름을 요약한 구성’이며 실제 캡처로 가장하지 않는다.

## 디자인·접근성

graphite #202124, warm paper #F3F0E8, sand #C7BBA8와 Gowun Batang / EB Garamond / Noto Sans KR을 유지한다. 문턱 SVG는 실제 현장 사진이 아닌 기존 구성 이미지다.

네이티브 세로 스크롤·키보드·reduced motion·확대를 유지한다. 일반 반응형과 /mobile/을 동기화하며 모바일 전용 경로는 넓은 화면에서도 한 열을 유지한다.

Chore to Play의 여섯 동시 관점과 입체 탐색은 기존 연구 페이지에 보존한다. 홈의 세 관점과 합치거나 단계·점수로 바꾸지 않는다.

## 사업자정보·연락

사용자 확인 번호 **247-02-04104**만 단일 원본 assets/js/site-config.js에 반영한다. 회사 등록명·법인 여부·대표자 필드·주소·전화는 추정하지 않는다. 정부 기관 조회로 검증했다고 주장하지 않는다.

scripts/sync_business.py로 정적 푸터를 동기화한다. site.js는 기존 행을 갱신하여 중복을 만들지 않고 textContent로 안전하게 표시한다.

기존 공개 메일 weplace25@gmail.com을 유지한다. 새 전용 계정·문의 서버·예약·결제·CRM을 만들지 않는다. 실제 동작은 메일 작성과 복사다.

현재 Netlify 호스트를 메타데이터에 유지하고 새 경로를 사이트맵에 추가한다. /mobile/은 루트 canonical, /preview/는 기존 noindex를 유지한다.
